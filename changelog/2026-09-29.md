# File Upload is here
Version: 1.3.0

A new upload component, a runnier Goo Switch, and you can now ask for what you're missing.

- NEW file-upload: An upload panel whose files drip out of the dropzone as liquid, then queue, pause, fail and retry in compact cards.
  - **Drag preview:** a badge with the file type and count follows your cursor over the dropzone
  - **Upload queue:** two uploads run at once by default, the rest wait their turn (`concurrency`)
  - **Pause and resume:** set `resumable` and each card gets a pause button
  - **Retry in place:** a failed upload turns red with a Retry button
  - **Validation:** `accept`, `maxSize` and `maxFiles` turn the dropzone red with a clear message
  - **Paste to upload:** Ctrl/Cmd + V drops a copied screenshot straight in
  - **Smart badges:** each file type gets its own color and glyph, images show a thumbnail
  - **Form-ready:** set `name` and a plain form submit carries the finished files
  - **Download:** pass `onDownload` and finished files get a Download button
  - **Use it whole or in parts:** the full `FileUploader`, or just `FileDropzone` or `FileUpload` cards
- UPDATED goo-switch: The tail it trails is now a rounded teardrop instead of a sharp wedge, so it reads as liquid.
- NEW: [Request a component](https://ui.devigner.cc/request) and vote on the [public requests board](https://ui.devigner.cc/requests).
- UPDATED: Component pages play soft interface sounds on clicks, and you can switch them off.
- UPDATED: A catalog search that finds nothing now offers to request that component.
