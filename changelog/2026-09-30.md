# Slider is here
Version: 1.4.0

A new slider, a prompt you can hand to your AI assistant, and a steadier Menu Dock.

- NEW slider: A slider whose fill heats from yellow to red as it grows, with a glass thumb that opens to show the value while you drag.
  - **Glass thumb:** the frosted thumb opens on press or keyboard focus and rolls the digits as the value changes
  - **Heat gradient:** the colors ride the fill's end, so red only shows as it nears full (restyle it with `classNames.fill`)
  - **Fluid or stepped:** glides after the pointer by default, set `snap` to jump stop to stop
  - **Commit callback:** `onValueCommit` fires once on release, for saves too heavy to run on every move
  - **Any direction:** horizontal or vertical, and `inverted` fills from the other end for right-to-left layouts
  - **Step marks:** a hairline mark per step, on or off with `marks`
  - **Full keyboard:** arrows, Page Up, Page Down, Home and End
  - **Form-ready:** set `name` and it submits like an input and resets with the form
  - **Custom text:** `format` shows and reads out values like `72°`
  - **Any size:** `sm`, `md`, `lg` or a thickness in px
- FIXED menu-dock: A dock with labels no longer locks in a squeezed width after a panel closes, and opens at its full width from the first frame.
- FIXED inline-time-edit: The pen icon now sits centered in its button.
- NEW: Every component page has a Prompt panel: copy a step-by-step setup prompt for your AI assistant, or open it straight in Claude, Codex or v0.
- NEW: A Share panel sends a component's page to X, LinkedIn, Reddit, Bluesky, Facebook or WhatsApp, or copies its link.
- UPDATED: Code on component pages highlights faster, with a lighter highlighter that loads no WASM.
- UPDATED: A new site footer with the newest component, previews on hover over the component links, and Devigner Icons.
