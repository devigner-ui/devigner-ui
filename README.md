# Devigner UI

Beautiful React components, built with Tailwind CSS. Copy-paste components and blocks for your next project.

## Getting Started

```bash
# Install in your project
npx devignerui init
npx devignerui add button
```

## Packages

| Package | Description |
|---------|-------------|
| `@devignerui/ui` | React component library |
| `@devignerui/cli` | CLI installer |
| `@devignerui/docs` | Documentation site |

## Development

```bash
# Install dependencies
pnpm install

# Start development
pnpm dev

# Build all packages
pnpm build
```
