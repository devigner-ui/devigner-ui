Devigner UI is a component catalog you install **into** your own project with a CLI,
rather than an npm package you import from. You own the code that lands in your
repository — Devigner UI owns the catalog, the docs site, and the installer that
delivers it.

## Vocabulary

Three words are used precisely throughout these docs:

- **Component** — a conceptual UI element with one slug, one category, one props
  contract. `button`, `hero-section`.
- **Style** — a distinct, independently-installable implementation of a Component.
  Styles can differ completely in markup and behavior. Selected via `--style` in
  the CLI. `default`, `gradient`, `magnetic` are all Styles of `button`.
- **Variant** — a prop value *within* a single Style's component API (for example
  `variant="outline"` on the `default` Button Style). Variants don't change which
  files get installed — Styles do.

Every Component ships at least one Style named `default`, which is always free
and stable. Additional Styles may be free or Pro.

## Browsing components

The full, interactive catalog — live previews, the style switcher, and props
tables — lives at [`/components`](/components). These guides cover everything
around that catalog: installing the CLI, theming, and conventions.
