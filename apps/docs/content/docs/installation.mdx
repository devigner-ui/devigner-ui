---
title: Installation
description: Set up the CLI, then add your first component.
---

Devigner UI assumes a Tailwind CSS v4 + React project. There's no `npm install`
of a component package in the primary flow - the CLI writes source files
directly into your project.

## 1. Initialize

```bash
npx devignerui init
```

This creates a `components.json` config file and a `components/ui` directory
(both configurable - see `--path`, `--css`, and `--tailwind` flags).

## 2. Add a component

```bash
npx devignerui add button
```

This writes the component's source file into your project and prints any npm
dependencies it needs (every component needs `cn`, which provides the `cn()`
class-merging helper).

## 3. List what's available

```bash
npx devignerui list
```

Filter by category:

```bash
npx devignerui list --category primitives
```

## Multiple components at once

```bash
npx devignerui add button card input
```
