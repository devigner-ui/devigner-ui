Dock ideas, one at a time

Each added to the settled dock on its own. Tick any you want (they combine), or none.

idea 1

Prev / next at the dock's ends

Step through the library in category order without opening the Components panel. Hovering an arrow names where it goes; [ and ] do the same from the keyboard. The dock grows by two icon buttons.

idea 2

Install command as the dock's last segment

The hero window's toolbar trick: the command and a copy button ride along in the dock, so installing is one click from anywhere on the page. Copy swaps to a check on the swap spring. Skip this if you pick top bar T2.

idea 3

Section scroll-spy replaces the inspector's tabs

When Docs opens, the Docs item widens into Install, Usage, Props, Notes and the active pill glides to the section you're reading on the layout spring. The inspector drops its tab row and scrolls as one document. Closing Docs folds them back into one item.
