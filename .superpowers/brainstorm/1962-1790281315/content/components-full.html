/components, full page

Same language as the home page: Geist titles with one Mazius word in cobalt, square stages, and the hero's selection frame reused as the card hover state (shown on Chart Card). There's no grid background anywhere. Each stage is a flat, softly lit surface. Use the switch at the bottom right to compare two card layouts:

  • A · Hairline grid (recommended). The cards sit in one connected grid split by 1px lines, like the bento on the home page.
  • B · Labelled frames. Separate frames with gaps. The name sits above each frame the way a design file labels its frames, and a Docs button sits next to the install command.

The toolbar sticks under the nav while you scroll. Every demo runs live, and only the cards near the viewport are mounted.
