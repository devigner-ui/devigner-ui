Install, polishedSame idea as your current section: a sentence with the commands in it, then a terminal and a file tree joined by a dotted line.
  • Chips: the commands in the sentence are proper chips now, each with a small icon and its own copy button. The file chip shows how many lines it adds.
  • Terminal: it has one tab per command, so "two commands" is literally visible. The output is colored the way a real CLI prints it, and a cursor blinks at the end.
  • File tree: glass, with folder and file icons, indent guides, and the new file glowing with "+214".
"commands" is set in Mazius.

Two commands, then it's your code

Run >_$ npx devignerui init once in your project. After that, >_$ npx devignerui add menu-dock writes tsxmenu-dock.tsx+214 into components/ui, and from then on it's a normal file in your repo.
