What we mean by manners

Calm when you ask for calm

Every component reads the reduced motion setting. With it on, springs and slides drop to a fade or stop moving entirely.

Fine without a mouse

Controls are real buttons and links with a visible focus ring. Menus and calendars also answer to the arrow keys and Escape.

Right in both themes

Colors come from CSS variables, so light and dark mode work without a single dark: class in the source.

Yours to rewrite

The CLI writes one .tsx file. Its props are typed and exported, and every class name sits in the file where you can change it.

Manners · four promises that are true for every component today, and the checklist every new one has to pass. "Fine without a mouse" needs the Timeline keyboard gap fixed or reworded before launch (see my note in the terminal).

Two commands, then it's your code

1npx devignerui init

Once per project. Creates components.json and a components/ui folder.

2npx devignerui add date-range-picker

Writes the component into components/ui and prints the npm packages it uses.

3Open the file

From here it's a normal component in your codebase. Change whatever you like.
