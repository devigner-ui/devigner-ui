Three directions for Devigner UI

Each one is a whole system: type, palette, how the home page is structured, and how the /components page presents a component (no grid backgrounds in any of them). The components shown here are static sketches. In the real build they are the live components. Click the one you want to take forward, or tell me what to mix.

A

Motion Study

Each component is shown the way a designer sketches motion: the frames between its states, laid out side by side and marked up in red pencil. The page makes the case for craft by showing the in-between that other libraries skip. Warm paper, a light serif, one red.

C

Inline

The page reads like one long sentence set in big type, and the components sit inside it as words you can use. There's almost no chrome: typography does the layout, and a floating install bar follows you down the page. Graphite, a characterful grotesk, one cobalt. This is the closest to today's hero idea, taken all the way.
