Two commands, then it's your code

Run $ npx devignerui init ⧉ once in your project. After that, $ npx devignerui add menu-dock ⧉ writes menu-dock.tsx into components/ui, and from then on it's a normal file in your repo.

What happens, in order, when the section scrolls into view: the command types itself, with a short pause before Enter. The output prints line by line exactly as the real CLI does. When the "✓ components/ui/menu-dock.tsx" line lands, a dotted cobalt line draws from it to the tree, and menu-dock.tsx slides into components/ui with its "new" tag. "Run it again" replays the whole sequence, and the npm line has its own Copy button. With reduced motion on, the final state appears at once. The terminal stays dark in both themes. On phones the tree drops below the terminal and the connector hides.
