Home page: three directions

Same title and the same giant footer wordmark in all three. Each mockup shows the first screen, then the section flow below it. Every component in these heroes would be the real, running component, not a picture of one. Click the one you want, then tell me in the terminal what you like or don't.

A

The Workbench

The Linear and Vercel move: headline on top, product window underneath. The window is a real mini app. It has a component list on the left, the live component in the middle, and an inspector on the right where you flip theme and reduced motion. The install command sits along the bottom. The window starts tilted back and flattens as you scroll.

B

The Canvas Recommended

devigner is designer plus developer, so the hero is both. The first screen is a design canvas you can drag around like Figma. Every component sits on it as a labelled frame, running live. Selecting a frame gives it handles and its size, and the floating toolbar switches to that component's install command. The next section is the handoff, where the selected frame turns into the file the CLI writes.

C

The Exploded View

The Apple and Stripe move, applied to "crafted". The hero shows one component pulled apart into the layers it's made of: the component, its motion, its keyboard map, its theme tokens and its code. As you scroll, the section pins and the layers snap together one at a time, each with a short caption. The page closes on the finished component and its install command.
