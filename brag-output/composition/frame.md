# Frame direction

This composition follows the Devigner UI site's own design language: a cool laboratory white canvas, graphite type, cobalt selection outlines, square component frames, a dark terminal, and compact design tool chrome. Use Bricolage Grotesque for the final wordmark. Keep the actual component browser and command legible at video scale.

## Avoid

- Generic gradient type, unrelated symbols, and abstract filler
- Rounded component frames that lose the design canvas appearance
- Tiny product UI text
- Unverified feature claims
