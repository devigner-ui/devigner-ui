# Brag Plan: Devigner UI

## What is this app?
Devigner UI is a catalog of animated, accessible React components that developers can preview and copy into a Tailwind CSS project with one command.

## The angle
The site feels like a design canvas, but the selected component becomes a normal file in your own repo. The film moves from a live component frame to a terminal command to the finished `.tsx` file. The final claim is ownership of the code.

## Hook (first 2.5 seconds)
An oversized cobalt selection box locks onto a live component. The line "Pick the part you want." lands beside it.

## Key moments
- A compact recreation of the actual Devigner component browser shows the Magnetic Button and Delete Button as selectable live frames.
- The selected Magnetic Button becomes the command `npx devignerui add magnetic-button`.
- A terminal reports `components/ui/magnetic-button.tsx`, and the file appears in a project tree.

## Outro
"Beautiful motion. Your code." with the Devigner UI wordmark and `devignerui`.

## User flow worth showing
Browse the component canvas, select Magnetic Button, run the add command, and receive `components/ui/magnetic-button.tsx` in the project.

## Tone
- Preset: polished
- Creative direction: a concise product film seen through a design tool
- Interpretation: composed camera moves, generous settled holds, quiet cobalt accents, and sparse interaction sounds.

## Format: landscape, 1920x1080
## Duration: 20 seconds

## Visual identity
- Background: `oklch(97.6% 0.003 260)` (approximate video RGB `#f7f8fa`)
- Accent: `oklch(53% 0.215 264)` (logo cobalt `#365ee9`)
- Text: `oklch(19% 0.012 260)` (logo ink `#151922`)
- Display font: Geist Sans, with Bricolage Grotesque for the wordmark
- Body font: Geist Sans; Geist Mono for commands and filenames
- Strongest visual element: the actual hero's component browser, framed like a design canvas with cobalt selection handles.

## Share copy (draft)
Pick a component, preview every state, then copy it into your repo. Devigner UI makes the animated part your code.

## Audio direction
- Role: restrained, polished music with precise UI accents
- Music: `happy-beats-business-moves-vol-12-by-ende-dot-app.mp3`
- Music treatment: low bed at roughly 0.3 volume, with a short fade at the end
- Audio-reactive treatment: subtle cobalt glow response to the music bed if extraction is available
- SFX posture: sparse, tied to the selection, command, file arrival, and final mark
- Audio-coupled moments: the selected component, the command being entered, and the completed file
- Restraint rule: no sound for every letter or every frame movement

## Music cue guidance
The bundled vol-12 cue preset estimates 109.96 BPM. The component selection near 8.74s and the completed file near 13.11s are useful strong cues. The final mark can settle near 18.56s. Cues support the edit only when reading time remains intact.

## Storyboard

### Scene 1 - Select - 2.5s
The real design-canvas language fills the frame: light ground, cobalt outline, corner handles, and a Magnetic Button preview. "Pick the part you want." settles for more than 1.2s.
Sequential/interaction: selection handles arrive in sequence around the component.
Audio intent: one soft placement sound beneath the music.
Transition mood: soft wipe into the browser.

### Scene 2 - Browse - 5.0s
A recreated Devigner component browser shows the sidebar, canvas frames, toolbar, and light/dark controls. The selected frame changes from Delete Button to Magnetic Button, with the cobalt selection moving to it. The UI itself remains readable.
Sequential/interaction: a cursor selects Magnetic Button at about 5.5s; the selection settles before the next scene.
Audio intent: quiet selection click.
Transition mood: smooth slide into the command.

### Scene 3 - Add - 4.0s
The browser toolbar's command expands into a full dark terminal. `npx devignerui add magnetic-button` appears, followed by `Adding components...` and the successful file path. The complete command and result hold together.
Sequential/interaction: simulate the command typing in short groups, then reveal the result as one readable line.
Audio intent: restrained key ticks and a soft confirmation cue.
Transition mood: clean wipe into the project tree.

### Scene 4 - Own - 5.0s
A project tree shows `components/ui/magnetic-button.tsx` placed in the repo. A code preview displays real React and Tailwind source character, while the line "A normal file in your repo." holds beside it.
Sequential/interaction: file row arrives, then the code panel opens.
Audio intent: light file placement sound.
Transition mood: soft crossfade to the final card.

### Scene 5 - End card - 3.5s
Devigner UI wordmark, cobalt mark, and "Beautiful motion. Your code." The terminal command remains as a compact footer.
Sequential/interaction: the mark lands first, then the final claim.
Audio intent: gentle final accent and music fade.

**Music mood for this video:** steady and clean.
**Audio summary:** a low music bed and four small sounds follow the path from selection to owned code.
